# Item placeholders / illustrated icons

Illustrated grocery icons (transparent PNGs, soft gradients + drop shadow) live in `icons/`.

- Generated by `scripts/generate_illustrated_icons.py` (~90 distinct icons).
- Catalog items map to the closest icon via keyword rules in `src/lib/placeholders.ts`.
- ItemCard prefers these images; emoji is last-resort fallback if the image fails to load.
- Optional: set `imageUrl` on a catalog item to override with a real product photo.
